# Memory Maintenance

Use this skill when the task involves curating CoderClaw's Markdown memory.

Rules:

- write durable facts, stable preferences, and long-term design decisions to `.coder_home/MEMORY.md`
- write short-horizon notes and daily context to `memory/daily/YYYY-MM-DD.md`
- prefer editing existing canonical files over creating redundant notes
- keep entries concise and auditable
