# Codex Home

This directory is the project-local Codex home used by CoderClaw.

When CoderClaw invokes Codex, it sets:

```text
CODEX_HOME=.coder_home/codex
```

This allows project-specific Codex steering without mixing it into the user's global `~/.codex`.

Mutable artifacts generated by Codex in this directory should remain untracked.
